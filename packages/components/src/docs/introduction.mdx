# onec

Un composant de design system, de bout en bout : contrat, tokens, code, tests, documentation, Figma et publication.

| Paquet             | Rôle                                                    |
| ------------------ | ------------------------------------------------------- |
| `@onec/tokens`     | Tokens DTCG, 4 thèmes (B2C, B2B × clair, sombre)        |
| `@onec/icons`      | Icônes Lucide en SVG sources                            |
| `@onec/components` | Web Components Stencil : `<onec-button>`, `<onec-icon>` |
| `@onec/react`      | Wrappers React générés                                  |
| `@onec/angular`    | Composants Angular standalone générés                   |

La marque et le schéma se changent dans la barre d'outils, en haut de chaque story.

- Code source : [github.com/FredOglz/onecomp](https://github.com/FredOglz/onecomp)
- Contrat du Button : [docs/contracts/button.md](https://github.com/FredOglz/onecomp/blob/main/docs/contracts/button.md)
- Décisions d'architecture : [docs/adr](https://github.com/FredOglz/onecomp/tree/main/docs/adr)
