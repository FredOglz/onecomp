## Ce que contient ce Storybook

| Section           | Contenu                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------ |
| **Démarrer**      | Un parcours par profil : designers, React, Angular, HTML                                   |
| **Design tokens** | Les trois niveaux de tokens, leurs valeurs dans les 4 thèmes, et leur nom dans Figma       |
| **Composants**    | Une page de doc par composant, puis ses stories : rendu, contrôles, code et maquette Figma |

Dans chaque page de composant, le code s'affiche **en React, Angular ou HTML** : le choix se fait une fois et vaut pour toutes les pages.
Dans chaque story, l'onglet **Design** du panneau du bas montre la maquette Figma à côté du rendu.
La marque (B2C, B2B) et le schéma (clair, sombre) se changent dans la barre d'outils, en haut.

## Les paquets

| Paquet             | Rôle                                                    |
| ------------------ | ------------------------------------------------------- |
| `@onec/tokens`     | Tokens DTCG, 4 thèmes (B2C, B2B × clair, sombre)        |
| `@onec/icons`      | Icônes Lucide en SVG sources                            |
| `@onec/components` | Web Components Stencil : `<onec-button>`, `<onec-icon>` |
| `@onec/react`      | Wrappers React générés                                  |
| `@onec/angular`    | Composants Angular standalone générés                   |

Un seul composant, écrit une fois en Web Component : les versions React et Angular sont générées à chaque build, elles ne divergent jamais.

- Décisions d'architecture : [docs/adr](https://github.com/FredOglz/onecomp/tree/main/docs/adr)
