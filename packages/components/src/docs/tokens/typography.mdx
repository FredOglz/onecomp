# Typographie

Les tailles sont en `rem` dans le code, pour suivre le réglage de taille de texte du navigateur ; Figma n'ayant pas d'unité `rem`, elles y sont converties en pixels (base 16 px).
Dans Figma : collection **Primitives**, groupe `font`.

<Typography />

L'interlignage est sans unité (1,25) dans le code. Dans Figma, il est posé à 125 % sur les textes, sans liaison de variable : Figma lirait la variable comme 1,25 px.
