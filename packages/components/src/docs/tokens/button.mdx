# Tokens du Button

Le Button ne lit que ces tokens. Chacun pointe vers un token sémantique : changer une couleur du bouton, c'est changer la référence ici, dans `packages/tokens/src/components/button.json`.
Dans Figma : collection **Components**, mêmes noms avec des barres obliques ; le composant Button y est lié variante par variante.
