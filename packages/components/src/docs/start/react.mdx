# Développeurs React

`@onec/react` expose chaque Web Component comme un composant React typé : `OnecButton`, `OnecIcon`.
Les wrappers sont générés à chaque build depuis le composant Stencil : mêmes propriétés, mêmes événements.

## Installer

Les archives des paquets sont jointes à chaque [release GitHub](https://github.com/FredOglz/onecomp/releases).

<Source
  dark
  language="bash"

## Utiliser le Button

<Source
  dark
  language="tsx"
  code={`import { OnecButton, OnecIcon } from '@onec/react';

<OnecButton variant="outlined" color="neutral" size="large" onClick={download}>
  <OnecIcon slot="icon-start" name="download" />
  Télécharger
</OnecButton>`}
/>

| Propriété React       | Type                                                                                   | Défaut        |
| --------------------- | -------------------------------------------------------------------------------------- | ------------- |
| `variant`             | `'contained' \| 'outlined' \| 'ghost'`                                                 | `'contained'` |
| `color`               | `'primary' \| 'secondary' \| 'neutral' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'primary'`   |
| `size`                | `'small' \| 'medium' \| 'large'`                                                       | `'medium'`    |
| `disabled`, `loading` | `boolean`                                                                              | `false`       |
| `type`                | `'button' \| 'submit' \| 'reset'`                                                      | `'button'`    |
| `name`, `value`       | `string`                                                                               | —             |

- **Événements** : `onClick` comme sur un bouton natif. Il n'est pas déclenché quand le bouton est `disabled` ou `loading`.
- **Formulaires** : `type="submit"` envoie le `<form>` parent avec `name` et `value`, `type="reset"` le réinitialise.
- **Icônes** : `<OnecIcon slot="icon-start" />` ou `slot="icon-end"`. Les noms disponibles sont listés dans `packages/icons/icons.json` du dépôt.
