# Développeurs Angular

`@onec/angular` expose chaque Web Component comme un composant Angular **standalone** : `OnecButton`, `OnecIcon`.
Les composants sont générés à chaque build depuis le composant Stencil : mêmes entrées, mêmes événements.

## Installer

Les archives des paquets sont jointes à chaque [release GitHub](https://github.com/FredOglz/onecomp/releases).

<Source
  dark
  language="bash"
  code={`pnpm add ./onec-angular-0.1.0.tgz ./onec-components-0.1.0.tgz ./onec-tokens-0.1.0.tgz ./onec-icons-0.1.0.tgz`}
/>

<Source
  dark
  language="typescript"
  code={`// data-brand et data-theme toujours ensemble, sur le même élément
@Component({
  selector: 'app-root',
  template: \`<main [attr.data-brand]="brand()" [attr.data-theme]="scheme()">…</main>\`,
})
export class App {
  readonly brand = signal<'b2c' | 'b2b'>('b2c');
  readonly scheme = signal<'light' | 'dark'>('light');
}`}
/>

## Utiliser le Button

<Source
  dark
  language="typescript"
  code={`import { Component } from '@angular/core';
import { OnecButton, OnecIcon } from '@onec/angular';

@Component({
selector: 'app-export',
imports: [OnecButton, OnecIcon],
template: \`
<onec-button variant="outlined" color="neutral" size="large" (click)="download()">
<onec-icon slot="icon-start" name="download"></onec-icon>
Télécharger
</onec-button>
\`,
})
export class Export {
download() {}
}`}
/>

- **Entrées** : `variant`, `color`, `size`, `type`, `name`, `value` en attributs ; `[disabled]` et `[loading]` en liaison (`[loading]="saving()"`), une entrée booléenne ne se pose pas en attribut nu avec les templates stricts.
- **Événements** : `(click)` comme sur un bouton natif. Il n'est pas émis quand le bouton est `disabled` ou `loading`.
- **Formulaires** : `type="submit"` envoie le `<form>` parent avec `name` et `value`, `type="reset"` le réinitialise.
- **Dépendance** : `rxjs` doit être présent dans l'application (c'est le cas de tout projet Angular).
